# Pocket Console PCB Keychain Fabrication Notes

## Board

- Design: BMO-inspired pocket-console LED keychain, original style
- PCB thickness: 1.6 mm FR4
- Copper layers: 2
- Finish: ENIG recommended
- Solder mask: teal/blue-green recommended
- Connector: USB-C receptacle, cable-powered, not a male plug

## Checks

- KiCad DRC: 0 violations
- KiCad ERC: 0 violations
- Unconnected items: 0

## Notes

- USB-C CC1/CC2 use 5.1k Rd pull-downs for default 5 V.
- Confirm the GCT USB4125-GF-A-0190 connector footprint before ordering parts.
- Order as a prototype first and inspect connector fit, keyring strength, and artwork alignment.
